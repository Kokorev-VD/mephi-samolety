# Карточка домена: сессии задач

Версия: 0.2. Дата: 05.11.2026. Владелец: Анохин Г.А. Статус: проект описания целевой системы.

## Назначение и границы

Домен создаёт пользователю набор задач по доступной конфигурации, принимает ответы, определяет результат и контролирует срок. Для внешних участников он описывается через операции создания сессии и отправки ответа. Устройство генераторов и алгоритмы проверки относятся к криптографическим доменам.

| Смежная область | Что требуется домену |
|---|---|
| Аутентификация | Подтверждённая личность пользователя и полномочия |
| Группы и конфигурации | Группа пользователя, включённые конфигурации и состав выбранного набора |
| Криптографические домены | Генерация условия и предметная проверка для каждого поддерживаемого типа |
| Хранение | Состояния сессии и задач, принадлежность и серверное время создания |

## Сценарии

При создании набора система проверяет доступность конфигурации для группы и отсутствие другой незавершённой сессии пользователя. Затем формирует задачи и возвращает созданную сессию. Её состав определяется выбранной конфигурацией.

При отправке ответа система устанавливает пользователя и задачу, проверяет принадлежность, состояние и своевременность запроса. После проверки формата решение передаётся проверяющему соответствующего типа. Вердикт определяет итог задачи; когда завершены все задачи, определяется итог сессии.

## Срок и попытка

Обозначения: `t0` — серверное время создания сессии; `D = t0 + 20 минут` — общий срок; `t_in` — время получения сервером полного запроса с ответом. Все задачи сессии используют один `D`.

| Условие | Правило |
|---|---|
| `t_in < D` | Ответ своевременный. При выполнении остальных условий он допускается к проверке |
| `t_in >= D` | Новый ответ отклоняется по сроку |
| Своевременная проверка закончилась после `D` | Её вердикт принимается; истечение времени во время работы сервера не отменяет своевременный ответ |
| Получен вердикт «верно» или «неверно» | Расходуется единственная попытка задачи; устанавливается итоговое состояние |
| Ошибка формата или нет обязательного поля | Предметная попытка не расходуется; исправленный запрос допустим только при его получении до `D` |
| Технический сбой без вердикта | Предметная попытка не расходуется; новый запрос допустим только до `D` |
| После `D` нет результата и нет своевременного ответа, ожидающего проверки | Незавершённая задача получает `FAILED` по просрочке |

Обновление страницы, ошибки и повторные обращения не изменяют `t0` и `D`. Если своевременная проверка завершилась техническим сбоем уже после `D`, повторный ответ не допускается; задача завершается по просрочке. Основание завершения — общий срок; предметная попытка остаётся неиспользованной.

Пока своевременный ответ обрабатывается, задаче не назначается просрочка. Одновременные обращения не должны приводить к двум завершённым предметным проверкам одной задачи. Программные обязанности по согласованию проверки и планировщика определены в [DOC-06.2](../07_Программные_требования/DOC-06.2_Сессии_задач_и_планировщик.md).

## Итог сессии

Сессия остаётся `NEW`, пока существует задача без итогового состояния, в том числе своевременный ответ в обработке. После завершения всех задач сессия получает `SOLVED`, если все задачи решены верно, и `FAILED` в остальных случаях. Ранее определённые результаты задач сохраняются при завершении по сроку.
