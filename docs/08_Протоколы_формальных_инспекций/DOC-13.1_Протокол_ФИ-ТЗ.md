## Решение инспекции

Отметить одно:

- ( ) **ПРИНЯТО** — документ принимается без изменений; все замечания закрыты и подтверждены на момент решения.
- ( ) **ПРИНЯТО С ЗАМЕЧАНИЯМИ** — открыты только Minor; срок закрытия — до конца следующего спринта; контроль закрытия — ведущий.
- ( ) **НА ДОРАБОТКУ** — имеются незакрытые Major либо существенная переработка; назначается повторная формальная инспекция.
