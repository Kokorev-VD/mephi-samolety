## Принятые предметные решения

Общий срок сессии составляет 20 минут. Одна попытка означает одну завершённую предметную проверку. Ошибка формата и технический сбой проверки попытку не расходуют. Ответ, полученный сервером до срока, считается своевременным, даже если проверка закончилась позднее. Последнее правило уточнено Анохиным 05.11.2026.

Исходные документы в папках 00–12 сохраняются. Новые Markdown-документы описывают рабочую редакцию; они не подтверждают автоматическую замену утверждённой версии комплекта.
