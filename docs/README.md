## Как читать комплект

DOC-05 описывает наблюдаемое поведение и связи частей системы. DOC-06 распределяет общие обязанности между компонентами. DOC-06.2 определяет создание набора, приём ответа, работу со сроком, фиксацию результата и восстановление после сбоя. Форматы запросов и кодов ошибок собраны в его приложении.

Сессия имеет общий срок 20 минут. Ответ, полученный до срока, допускается к завершению проверки после него. Обработка одного ответа ограничена 60 секундами от получения запроса; ожидание и перезапуск не продлевают этот предел. Попытка завершается фиксацией предметного вердикта. Ошибка формата и технический сбой без вердикта попытку не расходуют.

## Сборка

Markdown служит редактируемым источником. Генератор [build_pdf.py](build_pdf.py) объединяет связанные разделы, преобразует ссылки и создаёт самостоятельные `.tex` и `.pdf`. Общее оформление задано в [шаблоне](latex/document.tex): A4, шрифт 12 pt, полуторный интервал, поля 25/15/20/20 мм, титульный лист, журнал изменений и оглавление.

Для сборки нужны Python 3, Pandoc и Tectonic. Если программы доступны в PATH:

```sh
python3 docs/build_pdf.py
```

Пути к исполняемым файлам можно передать параметрами `--pandoc` и `--tectonic`. Режим `--tex-only` создаёт LaTeX без компиляции PDF. Журналы сборки и вспомогательные файлы сохраняются в `docs/.build/`, готовые результаты — рядом с основными Markdown-исходниками.

Сгенерированные `.tex` также допускают прямую сборку `pdflatex` в два прохода при наличии пакетов исходного оформления репозитория. Изменения содержания вносятся в Markdown с повторной сборкой, чтобы три представления одного документа оставались одинаковыми.

Для одновременного обновления печатных копий в корневых папках используйте `python3 docs/build_pdf.py --root-copies`. Копируются только `.tex` и `.pdf`; ссылки в них рассчитываются для соответствующего расположения.

Основной файл системных требований в корне — `04_Системные_требования/Системные_требования.pdf`; он обновляется вместе с одноимённым `.tex` и копией с префиксом `DOC-05`. Все эти файлы содержат одну текущую редакцию.
